## Run locally

No build step or package installation is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/arbazfareed/arbaz-portfolio.git
   cd arbaz-portfolio
   ```

2. Open `index.html` in a browser, or serve the folder with a local static web server.

Keep the profile photo and project screenshots in their existing locations so they load correctly:

- `Arbaz .png`
- `assets/induscart-store.png`
- `assets/skincare-storefront.png`

## Deployment

The site is a static website and is published with GitHub Pages from the repository’s `main` branch. After pushing changes, visit the [live portfolio](https://arbazfareed.github.io/arbaz-portfolio/) and hard-refresh with **Ctrl + F5** if an older cached copy appears.
